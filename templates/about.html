Transaction Risk Analysis System

An enterprise-grade Artificial Intelligence application engineered to detect, classify, and prevent fraudulent banking transactions in real-time using advanced Machine Learning algorithms.

MCA Final Year Project Machine Learning Predictive Analytics Cyber Security
Project Overview

The rapid digitization of financial services has exponentially increased the volume of digital transactions, simultaneously elevating the risk of financial fraud. Traditional rule-based detection systems are no longer sufficient to combat sophisticated cyber threats.

This project introduces a robust, scalable, and intelligent Transaction Risk Analysis (TRA) system. By leveraging supervised Machine Learning classifiers, the application analyzes complex behavioral patterns, transactional metadata, and geographical anomalies in milliseconds, providing an immediate risk assessment (Low, Medium, High) before a transaction is authorized.

System Architecture

1. Presentation Layer (Frontend)

Enterprise UI built with HTML/CSS/JS capturing transaction variables securely via REST API.

2. Application Layer (Flask)

Receives data, performs input validation, and routes variables to the ML pipeline.

3. Intelligence Layer (Scikit-Learn)

Pre-processes data via LabelEncoders and executes the serialized Random Forest model to compute probability.

4. Data Layer (MySQL)

Permanently logs the transaction details, prediction results, and timestamps for reporting and audits.

ML Model Workflow

1. Data Collection

Sourced highly imbalanced synthetic financial datasets representing modern banking.

2. Feature Engineering

Extracted spatial (distance), temporal (hour/day), and behavioral (failed logins) features.

3. Model Training

Trained multiple classifiers (Logistic Regression, Decision Trees, Random Forest). Random Forest yielded the highest F1-Score.

4. Deployment (Pickle)

Exported trained models and scalers using Joblib (.pkl) for rapid, stateless inference in production.

Dataset & Features

The model evaluates 20+ distinct features to make a deterministic decision. Key metrics include:

  • Transactional: Amount, Average Amount, Payment Method, Category.
  • Geospatial: Distance from home, Location, International flag.
  • Behavioral: Login attempts, Failed transactions, Account age.
  • Cyber: IP Risk Score, Device Type, New Device usage.

Key Platform Features

  • Real-Time Analysis: Millisecond latency for risk prediction.
  • Enterprise Dashboard: Live counters and automated charts.
  • History Tracking: Comprehensive audit logs of all predictions.
  • Secure Auth: Protected endpoints with session management.
  • Responsive UI: Glassmorphism styling optimized for all devices.
Future Enhancements

Model Retraining

Implement an automated pipeline to periodically retrain the model with new transactions stored in the MySQL database to prevent data drift.
